# MyMemes 🔊

مكتبة أصوات ضخمة — **17,979 صوتاً** في **14 قسماً** — مبنية بـ HTML/CSS/JS نقي (بدون أي إطار عمل) ومنشورة على Netlify.

🔗 **الموقع المباشر**: https://mymemes-app.netlify.app

## المزايا

- 🎵 **17,979 صوتاً** مقسمة على 14 قسم مع بحث فوري وترتيب حسب الأكثر تشغيلاً
- ▶️ **عداد تشغيل حقيقي**: يزيد عند كل تشغيل فعلي، محفوظ محلياً (localStorage) وعالمياً (Netlify Blobs) لكل الزوار
- 🌗 **وضع فاتح/داكن** مع زر تبديل وحفظ التفضيل
- 🌍 **ثلاث لغات**: العربية (RTL تلقائي) / English / Română
- ⬇️ **تحميل مباشر** عبر Netlify Function مع بروكسي يتجاوز حجب المصدر
- 📱 تصميم متجاوب كامل — زمردي، بدون إطارات عمل

## البنية

```
├── index.html              # الصفحة الوحيدة (SPA بسيط)
├── style.css               # التصميم الزمردي الكامل (فاتح + داكن)
├── app.js                  # كل المنطق: تشغيل، بحث، عدادات، ثيم، لغة
├── data/
│   └── sounds.json         # 17,979 صوتاً (slug, name, url, cat, plays, tags)
└── netlify/functions/
    ├── download.js         # بروكسي تحميل/تشغيل يتجاوز JA3 fingerprint
    └── plays.js            # عداد عالمي دائم عبر Netlify Blobs
```

## العداد (plays)

- عند بدء تشغيل الصوت فعلياً يُسجَّل: `+1` في الذاكرة، `+1` في `localStorage` للجهاز، و`POST /.netlify/functions/plays` للعداد العالمي
- العرض = أكبر قيمة بين (المصدر، العداد العالمي، عداد الجهاز) — لا ينقص أبداً
- الدالة الخلفية تستخدم `@netlify/blobs` مع بديل في الذاكرة عند تعطل Blobs

## النشر

يتم النشر تلقائياً إلى Netlify عند كل `push` إلى `main` عبر GitHub Actions (ملف `.github/workflows/deploy-netlify.yml`).

يتطلب سرّين في المستودع:
| السر | الوصف |
|------|-------|
| `NETLIFY_AUTH_TOKEN` | توكن Netlify الشخصي |
| `NETLIFY_SITE_ID` | معرف الموقع (8d33…4350) |
